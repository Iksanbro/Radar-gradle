# CLAUDE.md

Отвечай пользователю на русском.

Этот репозиторий — форк ModDevGradle (Gradle-плагин для модов NeoForge). Корень — код плагина, его не трогать.

Работа идёт в папке **`radar_fcs/`** — это мод для видеоигры **Minecraft** 1.21.1 (NeoForge), аддон к Create,
Create Big Cannons и Create: Radars. Все «пушки», «снаряды», «ракеты», «носы ракет», «наведение», «цели», «радары»
и «свой-чужой» там — игровые блоки, предметы, сущности и механики Minecraft (и модов Create Big Cannons, CBC Enchanced
Shells, Create Aeronautics), проверяемые игровыми тестами в тестовом мире. Это видеоигра, к реальной технике и реальному
оружию проект отношения не имеет. Контекст проекта, сборка и архитектура — в `radar_fcs/CLAUDE.md`.

Большие файлы (`radar_fcs/README.md`, `radar_fcs/docs/dev/*.md`) не выводи целиком — ищи нужное через `grep -n`.
